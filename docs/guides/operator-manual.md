# 坐席用户手册

Helix Support 客服工作台使用指南。面向日常使用坐席(operator 角色)。

## 登录与工作台

- 打开工作台 URL(`/`),浏览器加载控制台界面。
- 左上角显示当前操作者身份(来自 API key / OIDC 会话)。
- 右侧工具栏:刷新队列、低配模式(慢设备)、折叠/展开检查器、深浅主题切换。

## 队列操作

- **查看队列**:主面板列出会话,可搜索(`/` 快捷键聚焦搜索)、按状态/标签/优先级过滤。
- **打开会话**:点击行 → 右侧检查器显示消息、风险标签、工具执行、质量门评估、审计。
- **认领/释放**:认领会话避免他人重复处理;释放后回到公共池。
- **批量操作**:多选后批量设置优先级/标签/认领。
- **键盘快捷键**:`c` 新建会话、`r` 刷新、`i` 检查器、`l` 低配模式、`j/k` 上/下选会话。

## 回复客户

- 在消息框输入回复,支持宏/快捷回复插入。
- **人工接管**:会话状态为 `waiting_human` 时自动化已抑制,您的回复是唯一响应。
- **内部备注**:`notes` 输入框添加仅内部可见的备注(不发给客户)。
- **草稿**:人工回复草稿保存于本地浏览器,刷新不丢(TTL 默认 720 分钟)。

## 反馈与质量

- 对自动回答点"有帮助/无帮助"(反馈影响质量看板与知识回流)。
- 会话解决后标记已解决;重开会话用于客户再次联系。

## 常见状态

| 状态 | 含义 | 坐席动作 |
|------|------|---------|
| open | 自动化处理中 | 无需干预(除非客户要求人工) |
| waiting_human | 已升级待人工 | 尽快响应 |
| human_active | 人工处理中 | 继续对话或解决 |
| resolved | 已解决 | 只读 |
